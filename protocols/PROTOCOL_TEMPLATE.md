## 1. Claim under test
One sentence, falsifiable. Example: "With real-time chunking and a local
fallback, task success on the 5-task suite stays within 10 points of the
LAN baseline up to 300 ms median round-trip."

## 2. Primary metric and decision rule
- Primary metric: task success (binary per trial), reported per perturbation
  stratum and pooled.
- Statistical procedure: anytime-valid confidence sequences
  (`cairo_protocol.stats.anytime_cs`, alpha = 0.05) for each arm;
  comparisons by `sequential_compare` (alpha = 0.05, union bound).
  For fixed-n comparisons: Barnard exact test, one-sided, alpha = 0.05,
  Bonferroni across the K comparisons listed below.
- Stopping rule: stop an arm when its confidence sequence width is below
  0.15, or at the trial budget below, whichever comes first.
- Trial budget: N = ___ per arm per condition (from `trials_needed` with the
  minimum effect of interest below).
- Minimum effect of interest: ___ points of success.

## 4. Perturbation strata (LIBERO-Plus style, real world)
- Lighting: nominal / lamp off / lamp moved
- Distractors: none / 2 / 5 unseen objects
- Initial pose: nominal / +-3 cm / +-8 cm
- Instruction: canonical / paraphrase / (M-05) dialect
Trials are interleaved and randomised across strata and arms; the order is
generated by seed ___ and stored in `results/order.csv` before trial 1.

## 6. Hardware disclosure
Robot, firmware, controller rate, calibration date and residual, gripper,
camera model and exposure, force limits, payload, latency of the
observation-to-action chain as measured (not from a datasheet).

## 7. Compute disclosure
GPU type, hours, peak VRAM per run (from the VRAM assertion log), cost.

## 8. What counts as an intervention
Any human touch during a trial is logged with a code and the trial is
scored as a failure unless the protocol above says otherwise.

## 9. Video and logging
Every trial recorded; file name = `<trial_id>_<arm>_<task>_<stratum>.mp4`;
SHA-256 of each file written to `results/log.csv` at the end of the trial,
before the outcome is analysed.

## 10. Deviations
Any change to this file after trial 1 is a new commit with the reason in
the message, and is listed in the paper's Limitations section.
